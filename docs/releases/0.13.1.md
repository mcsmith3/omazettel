Ticked tasks stay ticked, and they now say when they were done.

## Fixes
- **Tasks ticked on the dashboard no longer come back after a sync.** If something outside OmaZettel had changed the open note (an AI agent, a script, another editor), the editor kept the old text and stopped saving that note until you answered a question about it. A tick from the dashboard, or one typed in the note, then never reached the file, and the task showed as open again. Dashboard ticks now always go straight into the note's file.
- **The open note reloads quietly when it changes outside OmaZettel,** keeping your place, as it already did after a sync. It only asks which version to keep when you have unsaved edits of your own.

## New
- **Ticked tasks are dated.** Ticking a task, on the dashboard or by typing an `x` in its box, adds the day at the end: `- [x] Send the deck (10/29/2026)`. Unticking it takes the date off. A done task you paste or type in whole keeps its text as written.

## Changed
- A tick from the dashboard is saved straight to the note, so Ctrl+Z no longer undoes it. Untick the box in the note instead.

## Install
On Omarchy or Arch Linux:
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
Or install it from OmaStore. Use one or the other, not both.
**Update:** run the same line again (OmaStore updates on its own). Close OmaZettel before updating. **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

On macOS, from your omazettel folder: `git pull && ./bin/install`.

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
