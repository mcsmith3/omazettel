A dashboard: what you've been writing, what's still open, and which notes need a look, all on one screen.

## New
- **Dashboard.** Press Ctrl+Shift+H, click the grid button at the top of the sidebar, or pick "Dashboard" in the command palette. It shows in place of the editor; click a note or press Esc to go back to writing.
  - **Activity:** a square for each day of the past year, darker the more notes you made or changed. Hover over a day for its numbers, or click it to list that day's notes. With Sync on, the days come from your version history; without it, from file dates. Above it: your note count, open tasks, days written in a row and new notes this week.
  - **Projects:** each project with its note count, open tasks and when it last changed. Click one to open its map of content.
  - **Open tasks:** every `- [ ]` task in your notes, grouped by note, newest first. Tick the box to mark it done, or click the task to jump to it in its note. Type in the filter to show only tasks with a name, word or project in them, such as everything assigned to you.
  - **Needs a look:** links to notes that don't exist, notes nothing links to, and empty notes.
  - **Top tags** (click one to see its notes) and **recently changed** notes.
- **`omazettel dashboard`** gives the same overview on the command line and to AI agents, so you can ask "what did I work on this week?" or "what's open on the Acme project?".

## Install
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
Or install it from OmaStore. Use one or the other, not both.
**Update:** run the same line again (OmaStore updates on its own). Close OmaZettel before updating. **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
