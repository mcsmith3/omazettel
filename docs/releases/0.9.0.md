New notes folders can now start "AI-first": a numbered folder layout with your own rules for AI agents, based on [this folder system](https://artificialcorner.com/p/claude-file-system).

## New
- **AI-first or traditional.** The first time you open an empty notes folder, OmaZettel asks how to start it:
  - **AI-first** makes `01-system` (your rules for agents), `02-context` (reference material), `03-projects` (active work; daily and meeting notes go here), `04-outputs` (finished work) and `99-archive`.
  - **Traditional** keeps things as before: just your notes, with `Daily/`, `Meetings/` and `Literature/` made as you use the templates.
  
  The answer applies to new folders from then on. Change it in Settings under "New, empty notes folders start". A folder that already has notes is never asked and never changed.
- **Your rules for AI agents.** An AI-first folder starts with `01-system/SYSTEM-RULES.md` (where things go, how to name files, how to edit) and `01-system/HOW-I-WORK.md` (about you; fill it in). Agents using the `omazettel` command or the MCP server get both files from `omazettel info` and are told to follow them before changing anything. OmaZettel writes these files once and never changes them.
- **File names that say when, what and how far along.** Agents are asked to put the date first for anything tied to a day (`2026-10-26-kickoff`), add a status to drafts and outputs (`2026-10-26-q4-plan-final`), and keep plain topic names for lasting ideas so links read well.
- **`omazettel setup-layout`** moves a folder you already have to the AI-first layout:
  ```
  omazettel setup-layout            # shows what would change, changes nothing
  omazettel setup-layout --apply    # does it
  ```
  It moves `Daily`, `Meetings`, `Literature` and `Archive` into the layout, points your templates there, and rewrites links so nothing breaks. It never overwrites a file. Your other folders stay where they are, and it tells you which ones they are. Agents can use it too, as the MCP tool `setup_layout`.

## Install
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
Or install it from OmaStore. Use one or the other, not both.
**Update:** run the same line again (OmaStore updates on its own). Close OmaZettel before updating. **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
