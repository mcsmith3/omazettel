OmaZettel now runs on macOS, and syncing is safer to set up on a new computer.

## New
- **macOS (early).** OmaZettel builds on a Mac with Qt and Poppler from [Homebrew](https://brew.sh):
  ```
  brew install qtbase qtdeclarative qtsvg poppler-qt6 pkgconf pandoc
  git clone https://github.com/mcsmith3/omazettel.git
  cd omazettel && ./bin/install
  ```
  `./bin/install` builds OmaZettel.app and puts it in Applications. Finder can open Markdown notes and PDFs with it, and the PDF viewer works. Shortcuts use ⌘ where Linux uses Ctrl. Find and replace is ⌥⌘F, because ⌘H hides the app on a Mac. Recording transcription isn't set up for macOS yet. Every change is now built and tested on a Mac as well as on Linux. To update, run `git pull` and `./bin/install` again.

## Fixes
- **Sync no longer uses a git repository that covers your whole home folder.** If your home folder is a git repository (some people keep settings files that way), OmaZettel used to treat it as the notes' history, and a sync would try to save and send everything in your home folder. It now leaves that repository alone and starts one just for the notes folder.
- **Sync gets past leftover lock files.** When a git step is stopped partway, it no longer leaves a lock that blocks every sync after it. A lock over ten minutes old is cleared automatically. A newer one gets a plain explanation, instead of git's "remove the file manually to continue".
- **Remote addresses are checked when you save them.** An address like `https://github.com:you/notes.git` (an SSH-style colon in an https address) or `github.com/you/notes.git` (no https://) is refused, with the corrected address shown.

## Changed
- **Moving to a new computer:** Sync & history and the README now say to clone notes you already sync (`git clone https://github.com/you/notes.git ~/Notes`) and open that folder, rather than setting up history again.

## Install
On Omarchy or Arch Linux:
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
Or install it from OmaStore. Use one or the other, not both.
**Update:** run the same line again (OmaStore updates on its own). Close OmaZettel before updating. **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

On macOS, see New above.

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
