Meetings recorded with Meeting Recorder now become meeting notes on their own, and PDFs and exports move out of the way of your notes.

## New
- **Meeting notes from [Meeting Recorder](https://github.com/jankeesvw/omarchy-meeting-recorder).** Meeting Recorder records any call (your microphone and what the computer plays) without a bot joining, and tells the speakers apart. Give `omazettel transcribe` a meeting's folder, its `transcript.md`, or `meeting-recorder:latest`, and with `--note` you get a meeting note with:
  - the meeting's own name, date and start time;
  - the speakers you named, as attendees;
  - its chapters as a guide for the agenda;
  - a link to the recording.

  A meeting gets one note. Running it again finds that note, and `--again` writes another. To have every meeting become a note as soon as its transcript is done, add this action to `~/.config/omarchy-meeting-recorder/config.toml`:
  ```toml
  [[action]]
  name = "Meeting note in OmaZettel"
  command = 'omazettel transcribe "$MEETING_DIR" --note --plain | grep "^Created"'
  auto = true
  ```
  For an older meeting, run the action from Meeting Recorder's Actions menu.
- **Meeting notes are filed by project.** With the folder layout, a meeting note goes in `03-projects/<project>/`. The project is the one named with `--project`, else the one the meeting's name starts with ("uci demo planning" goes in `03-projects/uci/`), else the one the AI finds the meeting is about.
- **Recordings are transcribed with Meeting Recorder when it's installed.** `omazettel transcribe` on an audio or video file uses it to tell the speakers apart, before trying Voxtype or whisper.cpp.

## Changed
- **PDFs and exports go in an `assets/` folder beside their notes,** so each folder shows its notes. The sidebar lists `assets` like any folder, and PDFs there open in the PDF view. In Settings you can still save exports next to the note, or in an `Exports` folder kept out of sync.
- **`omazettel setup-layout` moves existing PDFs and exported files** (`.pdf`, `.docx`, `.odt`, `.pptx`, `.epub`, `.rtf`) into `assets/` beside their notes, and rewrites links to them. Run it alone first to see what would move, then with `--apply`.

## Fixes
- **Turning off maps of content takes effect straight away.** An update that was already due could still write a map just after you turned them off.

## Install
On Omarchy or Arch Linux:
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
Or install it from OmaStore. Use one or the other, not both.
**Update:** run the same line again (OmaStore updates on its own). Close OmaZettel before updating. **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

On macOS, from your omazettel folder: `git pull && ./bin/install`. Meeting Recorder is Linux only.

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
