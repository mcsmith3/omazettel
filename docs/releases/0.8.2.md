Two fixes for how OmaZettel opens.

## Fixes
- **The sidebar shows the same complete tree every time.** It used to fill in folders in the background, so each launch could show a different half-loaded tree: some folders open, some closed, some notes missing until you reopened a folder. Now the whole notes folder is read at once when it opens (a few milliseconds). Changes from sync, the command line or AI tools still show up within a moment, and the folders you have open stay open.
- **One window.** Starting OmaZettel while it's already running, running `omazettel note.md`, or opening a Markdown file from the file manager now brings the existing window to the front and opens the file there (saving or asking about the open note first). Before, each start opened another window, and the windows overwrote each other's last note, recent folders and sync state. To open a second window anyway: `OMAZETTEL_NEW_INSTANCE=1 omazettel`.

## Install
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
Or install it from OmaStore. Use one or the other, not both.
**Update:** run the same line again (OmaStore updates on its own). Close OmaZettel before updating. **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
