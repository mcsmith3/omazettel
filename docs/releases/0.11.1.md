A small fix for the dashboard.

## Fixes
- **"Last changed" dates are right on synced notes.** After cloning your notes or pulling changes with Sync, every project on the dashboard showed as changed today, because it went by the date git wrote each file. Notes now go by when they were last saved as a version (or, if they have changes not yet saved, by the file's date). Recently changed notes are ordered the same way.
- **The summary tiles at the top of the dashboard stay the same height** when one label runs onto a second line.

## Changed
- The README now has a screenshot of the dashboard.

## Install
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
Or install it from OmaStore. Use one or the other, not both.
**Update:** run the same line again (OmaStore updates on its own). Close OmaZettel before updating. **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
