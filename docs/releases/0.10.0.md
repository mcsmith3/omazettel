Projects now get maps of content, transcripts get their own folder, and PDFs open right inside OmaZettel.

## New
- **Maps of content.** In an AI-first notes folder, `03-projects/projects-moc.md` links a map for each project, such as `03-projects/acme/acme-moc.md`. Each project map lists every note in that project, grouped by subfolder, so you (and AI agents) can see a whole project at a glance.
  - The maps update on their own when notes are added, moved, renamed or deleted, whether that happens in OmaZettel, through sync, from the command line or by an agent.
  - Only the list between two marker comments is rewritten. Anything you write above or below it stays.
  - Transcripts are never listed, so a map points you to the meeting summary, not the raw text. Daily notes get no map.
  - Turn maps off in Settings under "Keep maps of content for projects". `omazettel maps` shows which maps are out of date, and `omazettel maps --apply` updates them now.
- **Transcripts in their own folder.** `omazettel transcribe --note` now puts the transcript in a `transcripts/` folder beside the meeting note, so the folder shows the summaries. Running `omazettel setup-layout --apply` moves transcripts you already have.
- **View PDFs in OmaZettel.** PDFs in your notes folder, including the ones you export from a note, now appear in the sidebar. Click one to read it in the middle of the window: scroll through the pages, zoom with the − and + buttons or Ctrl+= and Ctrl+-, and click the zoom level to fit the page to the width. **Open** shows it in your desktop's PDF viewer. ✕, or clicking a note, takes you back to writing. If you export the note again, the PDF view refreshes.

## Changed
- OmaZettel now needs Qt 6.8 or newer (Arch ships 6.12).
- The package now depends on `poppler-qt6` to show PDFs. The install line below pulls it in. OmaStore installs can't add dependencies: if `poppler-qt6` is missing, everything else still works, and the PDF view tells you to run `sudo pacman -S poppler-qt6`.

## Install
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
Or install it from OmaStore. Use one or the other, not both.
**Update:** run the same line again (OmaStore updates on its own). Close OmaZettel before updating. **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
