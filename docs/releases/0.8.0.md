## What's new

### Transcripts get their own note
`omazettel transcribe meeting.vtt --note` now makes two linked notes: the meeting note (summary, Agenda, Notes, Decisions, Action items) and a separate `<meeting>-transcript` note that holds the full transcript. The meeting note links to the transcript, and the transcript links back. `--no-transcript` skips the transcript note.

### No more spaces in note file names
New notes are saved as `2026-10-22-Vendor-kickoff.md` instead of `2026-10-22 Vendor kickoff.md`. Titles inside your notes keep their spaces.
- **Settings → "Between words in new note file names"**: choose hyphen (the default), underscore or space.
- Links work whichever you use: `[[Vendor kickoff]]`, `[[vendor-kickoff]]` and `[[Vendor_kickoff]]` all open the same note, so older notes keep working.
- Renaming a note gives it a name in the new style, and links to it are updated.

### `omazettel tidy-names`
Renames your existing notes that have spaces in their file names, and updates every `[[link]]` to them.
```
omazettel tidy-names              # shows what would change, changes nothing
omazettel tidy-names --apply      # renames them
omazettel tidy-names Meetings     # limits it to one folder
```
Folders and exported files keep their names. It's also available to AI assistants as the MCP tool `tidy_names`.

### Also
- The README now has a copyright line.

### One-line install
OmaZettel now has a one-line installer, like other Omarchy apps.

## Install
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
It downloads this release's package, checks it against `SHA256SUMS`, and installs it with pacman. On ARM it builds the package from source instead.
**Update:** run the same line again. **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
