A small release: two bug fixes, ARM packages, and OmaStore.

## Fixes
- **Exporting a folder keeps notes in number order** on systems with no language set (such as `LANG=C`): `2 Two` now comes before `10 Ten`. Before, those systems sorted `10` first.
- **Theme colours work without Omarchy's colour tool.** When `omarchy-theme-color` isn't available, OmaZettel reads the theme's `colors.toml` itself, but that reader dropped every colour value, so tags and other highlights fell back to the accent colour.

## New
- **Install from OmaStore.** OmaZettel is now listed in [OmaStore](https://github.com/KitsuneForgering/OmaStore), the community app store for Omarchy (thanks @KitsuneSemCalda). The store installs it in your home folder without sudo.
- **ARM (aarch64) packages**, for both the one-line installer and OmaStore.
- **Releases are built and tested by GitHub Actions.** Both architectures build in a clean Arch container and must pass both test suites before anything is published. Each release includes `SHA256SUMS` and a build provenance attestation, so OmaStore can show it as built by this repository.

## Install
```
curl -fsSL https://raw.githubusercontent.com/mcsmith3/omazettel/master/install.sh | bash
```
Or install it from OmaStore. Use one or the other, not both.
**Update:** run the same line again (OmaStore updates on its own). **Uninstall:** `sudo pacman -R omazettel` (your notes are untouched).

OmaZettel is still early, so keep your notes folder backed up. It's a community project, not an official Omacom/Omarchy app.
